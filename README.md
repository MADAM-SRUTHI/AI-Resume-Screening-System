# AI-Based Resume Screening System

## 📌 Project Description

AI-Based Resume Screening System is a Django web application that allows users to upload resumes and automatically identify technical skills from them.

## 🚀 Features

- Resume Upload
- PDF and DOCX Resume Support
- Automatic Skill Extraction
- Keyword-Based Resume Screening
- Screening Result Generation
- Django Admin Dashboard
- SQLite Database

## 🛠️ Technologies Used

- Python
- Django
- HTML
- CSS
- SQLite
- PyPDF
- python-docx

## ⚙️ How to Run

1. Clone the repository
2. Install required packages
3. Run database migrations
4. Start the Django development server
5. Open the application in a browser
